# Clinic

A trio project with Ajan Mudey and Aisha Tasneem Muhammad. The work was shared equally. The API keeps doctors, patients, appointments, and medical records. An appointment can have one medical record.

This page runs the same checks in the browser.

Live page: https://nno3.github.io/clinic-api/

Open the page and load the sample clinic, then add a patient, a doctor, an appointment, or a medical record. The Java source is in `java/`. Copy `java/src/main/resources/application.properties.example` to `application.properties` and put in your own database password before running the API.
